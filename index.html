Enviar ou atualizar um script

Cole o código ou solte o arquivo .user.js. O nome, a versão e a descrição são lidos do cabeçalho do script. Se o arquivo já existir, ele é atualizado.

Como criar o token
  1. Abra o link “Criar token”, escolha “Only select repositories” e marque college.
  2. Em “Repository permissions”, defina Contents como Read and write.
  3. Gere o token, copie e cole no campo acima.
